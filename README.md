# Учусь рисовать — переносимый контекст

Этот пакет позволяет продолжить обучение рисованию аниме-персонажей без доступа к прежнему чату.

## Как начать новый чат

1. Сначала прочитайте `мой_прогресс.md` и `план_обучения.md` полностью.
2. Затем откройте только работы и референсы, относящиеся к текущему вопросу. Для текущей точки это `работы/первый_набросок_головы.jpeg`, `работы/второй_набросок_головы.jpg` и `референсы/референс_персонажа.jpeg`.
3. Давайте одно небольшое упражнение за раз: сначала конструкция и пропорции, затем детали. Не требуйте чистового рисунка, пока не проверена основа.
4. После занятия кратко предложите обновить `мой_прогресс.md`: что сделано, что заметно улучшилось, одна-две ошибки и следующий шаг. Не вносите предположения как факты.

## Содержимое

- `мой_прогресс.md` — текущая точка, наблюдения по работе и следующий шаг.
- `план_обучения.md` — гибкий план на 2–4 недели.
- `работы/` — значимые рисунки пользователя.
- `разборы/` — краткие заметки к ним.
- `референсы/` — ключевые исходники для упражнения.

Все сведения в пакете основаны только на доступной работе, референсе и предыдущем разборе. Неизвестное вынесено в разделы «Уточнить».
